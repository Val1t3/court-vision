# court-vision

## Repository Structure
The repository is organized into two main sections:

[research/](research/README.md) — Contains all experimental, deprecated, or unused files and assets created during the exploration and prototyping phases. This folder serves as an archive of previous approaches and trials.

[corpus/](corpus/README.md) — Contains the essential files and assets forming the official corpus for the thesis. This is the primary source of data and resources used in the final research work.
