# Court Vision

## Install Dependencies
```bash
pip install -r requirements.txt
```

---

## Point selection
```bash
python point_select.py "frame_path" "point_path"
```

---

## Run
You can modify `constants` variables to modify some parameters of the script:

- `show`: used to choose what type of analysis to display - Show.ALL, Show.BLENDED, Show.WARPED.
- `win_name`: name of the window.

```bash
python main_video_fix.py
```
